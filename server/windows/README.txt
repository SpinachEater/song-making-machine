Sheet music reader for Song Making Machine (Windows)

1. Double-click "Start sheet music reader.bat".
   - The first time, it installs the reader (about 5 minutes, needs internet).
   - If Python is missing, it opens the Python download page. Install Python,
     tick "Add python.exe to PATH" on the first screen, then double-click again.
   - If Windows shows "Windows protected your PC", click "More info", then "Run anyway".
2. Leave the black window open. Your browser opens Photo to Sheet Music.
3. Add a photo and press "Read the music".

Close the black window to stop the reader.
